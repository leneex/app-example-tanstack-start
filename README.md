# TanStack Start

Example [TanStack Start](https://tanstack.com/start) app. TanStack Start is a full-stack React framework built on TanStack Router.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | off |
| Project directory | `/` |
| Output directory | `/dist/client` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production with minification
npm run build

# preview the build locally
npm run preview
```
